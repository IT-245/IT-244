## One key decision made during this period

The team decided to use `persons` as a supertype and then create `patients`, `doctors`, and `nurses` as subtypes. This made the design cleaner and satisfied the requirement for specialization/generalization.

## One problem encountered

One challenge was choosing a specialization that was meaningful and still easy to map to relational tables. We solved this by using people-related roles because all of them share common person details but also need role-specific attributes.
